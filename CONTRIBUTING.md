# Как сдавать работу

Подробности — в разделе [«Как сдать?»](README.md#как-сдать) README.

Для зачёта нужны **трейс + отчёт** — без любого из них работа не засчитывается.

Коротко:

1. Сделайте **форк** репозитория.
2. Создайте папку `attacks/<ваша-фамилия>/` (шаблон — `attacks/_template/`).
3. Положите туда файл(ы)-атаки, заполненный `writeup.md` (отчёт) и доказательство —
   приложенный `trace.md` **или** ссылку на LangSmith внутри `writeup.md`.
4. Откройте **Pull Request** в этот репозиторий.

Менять можно **только** файлы внутри своей папки `attacks/<фамилия>/`.
Код агента, защиты, данные (`hr_agent/`, `data/`, `run.py`), системный промпт,
задачу агента и фактическую часть резюме трогать нельзя.
