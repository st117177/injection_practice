# Отчёт по атаке — Фамилия Имя

> Шаблон. Скопируйте папку `attacks/_template/` в `attacks/<ваша-фамилия>/`,
> положите рядом файл(ы)-атаки и заполните пункты ниже. Коротко, по делу.

## Комбо
- Цели: <например, A+B>
- Защиты в стеке: <например, spotlighting, repeat_task — или «без защиты»>
- Команда запуска:
  ```bash
  python run.py --attack attacks/<фамилия>/attack.md --defense spotlighting,repeat_task --goal A,B --runs 5
  ```

## Результат
- Комбо достигнуто: <да/нет>, в <N> из <M> прогонов
- Доказательство: <ссылка на LangSmith **или** приложенный trace.md в этой папке>

## Где прошла инъекция
Своими словами: какой фрагмент вашего текста в разделе «О себе» сработал и
на каком шаге трейса видно, что агент послушался данные, а не задачу.

## Почему защита пробита / держит
Если стек пробит — почему именно эта формулировка обошла защиту.
Если верхняя ступень не поддалась — почему защита не даёт достичь цели
(это такой же валидный результат, как пробой).
